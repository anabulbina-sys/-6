# lab -6
Задание 1.
Геометрические фигуры
Прямоугольник
Треугольник
Трапеция
Расчёт площади, радусов описанной и вписанной окружности.

Описание проделанной работы
Шаг 1: Установка библиотек
Откройте терминал (командную строку) и выполните: pip install appJar openpyxl python-docx
Создайте файл requirements.txt с содержимым:
text
appJar
openpyxl
python-docx
Что делает каждая библиотека: appJar — простой фреймворк для создания графического интерфейса, идеален для начинающих 
openpyxl — работа с Excel-файлами (.xlsx) 
python-docx — создание и редактирование Word-документов 

Шаг 2: Модуль прямоугольника
Создайте файл shapes/rectangle.py, с кодом для Радиус вписанной окружности прямоугольника. В прямоугольник можно вписать окружность, только если это квадрат (a = b).
Для квадрата: r = a / 2.

Шаг 3: Модуль треугольника
Создайте файл shapes/triangle.py. Здесь нужно больше формул — расчёты зависят от трёх сторон.

Шаг 4: Модуль трапеции
Создайте файл shapes/trapezoid.py. Для трапеции нужны два основания и высота.

Шаг 5: Инициализация пакета
Создайте файл shapes/__init__.py — он делает папку shapes пакетом и упрощает импорт.

Шаг 6: Основная программа с GUI
Создайте файл main.py. Программа создаёт окно с вкладками для каждой фигуры.

Шаг 7: Запуск программы
Откройте терминал в папке geometry_calculator
Выполните команду: python main.py
Появится окно с тремя вкладками — по одной для каждой фигуры
Введите параметры, нажмите кнопку расчёта
Сохраните результаты в Word или Excel
